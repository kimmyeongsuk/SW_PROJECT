지출 예측 가계부

202344042 김명석

기획 배경

무의도적 구독 결제를 방지하고
월 고정 지출을 한눈에 관리·시각화하기 위한 서비스


· 무료로 사용하다가 유료 결제로 바뀌어 나도 모르게 유료 구독 서비스가 결제되는 경우
· 과도한 지출이 발생한 경우가 생기는 일을 방지
· 매달 나가는 지출을 한 번에 계산,예측하고 한 눈에 알아보기 쉽게 하기 위해 기획

문제

기존 가계부의 부족한 기능

단순 수입, 지출 기록 중심

패턴이 안 보인다

어떤 날 지출이 몰리는지 알기 어렵다

고정 지출을 알려주지 않는다

각 각의 지출만 보여줘 사용자가 직접 계산해야하는 경우가 발생

핵심 기능

네 가지 기능

기능설명
기본적인 수입 / 지출 기록언제 지출을 했는지 수입이 들어 왔는지 보여준다
일별 지출 그래프지출이 몰리는 날 시각적으로 보여준다
정기 구독 관리고정 지출을 분류한다
예상 지출 계산고정 지출(구독료) 등을 한번에 계산하여 예측하는 기능

부가 기능

기능설명
빠른 입력자주 사용하는 카테고리/금액 자동완성 기능
반복 지출 원터치 등록 기능
카테고리어디에 가장 많이 썼는지 비교한다
모임 정산 인원 수별 금액 계산 기능
기술 스택

Java 기반

구분내용
BackendJava + Spring Boot
DatabaseMySQL
차트Chart.js

5~6주카테고리별 통계, 모임 정산 기능
7~8주빠른 입력 기능, UI 다듬기
