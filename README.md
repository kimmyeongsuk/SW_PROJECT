# SW_PROJECT
# 💰 지출 예측 가계부

> **월 고정 지출과 소비 패턴을 한눈에 확인하고, 앞으로의 예상 지출을 관리할 수 있는 가계부 서비스**

## 📌 프로젝트 소개

기존 가계부는 수입과 지출을 단순히 기록하는 데 집중되어 있어
사용자가 **고정 지출이나 소비 패턴을 직접 확인하고 계산해야 하는 불편함**이 있습니다.

이 프로젝트는 이러한 불편함을 해결하기 위해

* 수입 / 지출 기록
* 일별 지출 시각화
* 정기 구독 관리
* 예상 지출 계산

기능을 제공하는 **지출 관리 및 예측 가계부 서비스**를 개발하는 것을 목표로 합니다.

## 🎯 기획 배경

### 해결하고자 하는 문제

* 무료 이용 후 유료로 전환되는 구독 서비스를 놓치는 문제
* 월별 고정 지출을 직접 계산해야 하는 문제
* 특정 날짜에 지출이 집중되는 소비 패턴을 파악하기 어려운 문제
* 단순 기록만으로는 앞으로 발생할 지출을 예상하기 어려운 문제

## ✨ 주요 기능

| 기능            | 설명                      |
| ------------- | ----------------------- |
| 📝 수입 / 지출 기록 | 수입과 지출 내역을 기록하고 관리      |
| 📊 일별 지출 그래프  | 날짜별 지출 금액을 시각적으로 확인     |
| 🔔 정기 구독 관리   | OTT, 서비스 등의 고정 지출 관리    |
| 💰 예상 지출 계산   | 정기 지출을 기반으로 예상 지출 금액 계산 |

### ➕ 부가 기능

* **빠른 입력**

  * 자주 사용하는 카테고리 및 금액 자동완성
  * 반복 지출 원터치 등록
* **카테고리별 통계**

  * 카테고리별 지출 비교
* **모임 정산**

  * 인원 수에 따른 금액 계산
